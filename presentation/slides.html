Under the Hood

Technical Highlights

Browser-based
No installation needed
Runs entirely in Chrome or Edge. No server, no uploads, no dependencies to install.
WebP Encode/Decode
Frame-by-frame processing
Decodes animated WebP frame by frame, recolours each independently, re-encodes with original timing.
Pixel-perfect masks
Binary mask arrays
Each frame stores a Uint8Array mask per region — precise, fast, and losslessly serialised to JSON.
Electron app
Runs locally too
Can be launched as a desktop app via npm start on Windows for an offline-first experience.
